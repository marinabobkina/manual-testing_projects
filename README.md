<h2>Проект по ручному тестированию web-приложения</h2>
Полностью протестировала интернет-магазин «Skillbox», в ходе которого выполнила следующие задачи:

- тестирование аналитики, 

- проверка формы регистрации и авторизации, 

- создание диаграмму переходов и состояний, 

- создание тест-кейсов для регрессионного и приемочного тестирования,  

- тестирование API с помощью Postman,

- тестирование UI,

- тестирование безопасности. 

Найденные дефекты оформила в баг-репорты в приложении Youtrack.

[С результатами тестирования можно ознакомиться в Youtrack (доступ через VPN):](https://skillboxstudent.youtrack.cloud/agiles/159-4/current)
